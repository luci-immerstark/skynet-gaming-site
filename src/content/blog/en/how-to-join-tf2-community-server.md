To join a TF2 community server, open the game console and type `connect IP:port`, or add the server to your favorites in the server browser. Using ours as the example, the command is below. All you need is Team Fortress 2, which is free on Steam.

`connect 212.38.89.226:27015`

## Method 1: from the console

1. In TF2, open **Options → Keyboard → Advanced** and tick **Enable developer console (~)**.
2. In game, press the `~` key (tilde or backtick) to open the console.
3. Type the connect command and press Enter:

`connect 212.38.89.226:27015`

If you're on this website, you can also click **Play now** on the home page: the button launches TF2 already connected to the server through Steam.

## Method 2: from the server browser

1. In the TF2 main menu, go to **Find a Game → Community Servers**.
2. Open the **Favorites** tab and use the option to **add a server**.
3. Enter the address `212.38.89.226:27015` and confirm.
4. Double-click the server in the list to join.

*Exact menu names may vary slightly depending on the game version and language.* You can also open the server browser from Steam, under **View → Game Servers**.

## If you can't get in

- **Server full:** ours has 40 slots; try again in a moment.
- **Outdated game:** let Steam update TF2 and try again.
- **Connection failed:** double-check the IP and port, with no extra spaces.

Tip: add the server to your favorites so next time it takes two clicks. Before you play, read the [server rules](/en/#regras).
